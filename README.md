# SF Airbnb Listings
A simple webpage that displays the **first 50 Airbnb listings from San Francisco**, loaded from a JSON file using JavaScript `fetch` and `await` (AJAX).
 
## Live on GitHub Pages:
https://priyan-b.github.io/Airbnb-Listings/
 
## Contents in my webpage:
For each listing:
- Thumbnail image
- Listing name
- Host name + host photo
- Price per night
- Rating
- Description
- Top 5 amenities
  
## My Creative Additions:
**Sort Dropdown** — sort listings by price (low/high) or by rating

**Favorite Heart Button** — click the heart on any card to mark it as a favorite
